# [1.0.0] - 2026-08-02

## Initial Stable Release

This marks the first stable release of the **TVET Programme Impact Assessment** project.

### Added

- End-to-end Monitoring & Evaluation (M&E) capstone project.
- Digital survey design and implementation.
- Multi-platform data collection using:
  - KoboToolbox
  - CommCare
  - Google Forms
- Data cleaning and transformation using Microsoft Excel and Power Query.
- SQL Server database creation and analytical queries.
- Interactive Microsoft Power BI dashboard.
- Excel analytical dashboard.
- Executive PowerPoint presentation.
- Comprehensive technical documentation.
- Data dictionary.
- Project methodology.
- Final project report.
- Repository branding assets including:
  - Banner
  - Thumbnail
  - Workflow Diagram
  - Solution Architecture
