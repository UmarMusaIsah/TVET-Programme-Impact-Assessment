# Security Policy

## Overview

Thank you for your interest in the security and integrity of this repository.

The **TVET Programme Impact Assessment** repository is an educational and portfolio project developed to demonstrate practical skills in Data Analytics and Monitoring & Evaluation (M&E). While this repository does not contain production systems or sensitive infrastructure, responsible reporting of potential security concerns is appreciated.

# Reporting a Security Issue

If you discover a security concern related to this repository, please do not disclose it publicly before reporting it.

Instead, report the issue directly using the contact information below.

**Email**

umarmusapress@gmail.com

Please include:

- A clear description of the issue.
- Steps to reproduce the problem (if applicable).
- The potential impact.
- Any recommendations or supporting information.

---

# Response Process

Reported security concerns will be reviewed as quickly as possible.

Where appropriate, corrective actions may include:

- Updating project documentation.
- Revising repository content.
- Correcting exposed configuration issues.
- Improving repository security practices.

---

# Responsible Disclosure

Please avoid publicly sharing security-related issues until they have been reviewed.

Responsible disclosure helps maintain the integrity of the project and supports a constructive collaboration process.

---

# Scope

This policy applies only to the contents of this GitHub repository.

It does not apply to third-party services, software, or platforms referenced within the project.
