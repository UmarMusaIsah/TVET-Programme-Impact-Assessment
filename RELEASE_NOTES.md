# Overview

Version 1.0.0 represents the first stable release of the **TVET Programme Impact Assessment** project.

This repository demonstrates an end-to-end Data Analytics and Monitoring & Evaluation (M&E) workflow, covering digital data collection, data preparation, SQL analysis, dashboard development, technical reporting, and project documentation.
