# TVET Programme Impact Assessment

## Overview

This project evaluates the impact of a Technical and Vocational Education and Training (TVET) programme using data collected from programme participants. The survey was designed and deployed through KoboToolbox, CommCare, and Google Forms, while Microsoft Excel, SQL Server, and Power BI were used for data preparation, analysis, and visualization.

The project follows a complete data analytics workflow, from digital data collection to interactive dashboard development, with the aim of generating practical insights that support evidence-based decision-making.


## Project Objectives

- Collect high-quality survey data using digital data collection platforms.
- Clean and validate the collected data.
- Perform descriptive and exploratory data analysis.
- Conduct SQL-based analytical queries.
- Develop an interactive Power BI dashboard.
- Present findings and recommendations based on the analysis.
